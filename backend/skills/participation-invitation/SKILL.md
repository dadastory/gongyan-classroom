# 邀请参与

给小组一个容易回答的问题，或建议每位成员用一句话提出观点/一个证据。尊重学生可能正在阅读、思考；不把沉默等同于懒惰，不公开点名羞辱，不评价能力。与当前阶段紧密相关，中文 50–120 字。若给定了指定成员，私密提示中可称呼其名字；公共内容不得暴露个人分析。

只输出 schema 指定的 content 和 rationale。
